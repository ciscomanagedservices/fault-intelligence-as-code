# BGP_NEIGHBOR_ADMIN_SHUTDOWN — Fault Signature Analysis

## Syslog-to-Regex Mapping

| # | Source Syslog (from RG Event 1) | Event ID | Regex Pattern | Notes |
|---|---|---|---|---|
| 1 | `RP/0/RP0/CPU0:router: bgp[1056]: %ROUTING-BGP-5-ADJCHANGE : neighbor 10.1.1.1 Down - Admin. shutdown (VRF: default) (AS: 65001)` | E1 | `%ROUTING-BGP-5-ADJCHANGE\s*:\s*neighbor\s+(\S+)\s+Down\s+-\s+Admin\.\s+shutdown\s+\(VRF:\s*(\S+)\)\s+\(AS:\s*(\d+)\)` | Anchored to mnemonic + "Admin. shutdown" reason. Captures neighbor IP (group 1), VRF (group 2), AS (group 3). |

**Splunk variant (if needed):**
```
%ROUTING-BGP-5-ADJCHANGE\s*:\s*neighbor\s+(\S+)\s+Down\s+-\s+Admin\.\s+shutdown
```
Splunk regex can omit the VRF/AS capture groups if those fields are already indexed as structured fields.

## Condition Logic Rationale

Single-event signature (`logic: "E1"`). The administrative shutdown fault is fully
identified by one syslog message on the local router — no secondary event or
correlation window is required. The `logic_lookback_time` is set to `0` accordingly.

Event 2 (remote peer CEASE notification) was explicitly excluded from this signature
per design decision: the FMS monitors the local router only, and the remote peer
syslog is not reliably available in this deployment context.

## Detection Coverage Assessment

- **Catches:** BGP neighbor sessions placed into administrative shutdown via the
  `neighbor shutdown` IOS XR configuration command on any monitored router.
- **Misses:** Administrative shutdowns applied on the remote peer (not the monitored
  router). These would appear as a different syslog reason (e.g., "Peer closing down
  the session") and are intentionally out of scope.
- **False positive risk:** Low. The pattern is anchored to the specific mnemonic
  (`ROUTING-BGP-5-ADJCHANGE`) and the exact reason string (`Admin. shutdown`). Other
  BGP session-down reasons (hold timer expiry, interface down, etc.) produce different
  reason strings and will not match.

## Open Items for SME Review

1. **Regex stability across platforms:** Confirm the "Admin. shutdown" reason string
   is identical on ASR 9000, Cisco 8000, NCS 5500/5700, and NCS 540 across IOS XR
   7.x and later. Minor formatting differences (extra spaces, punctuation) could
   cause misses.
2. **IPv6 neighbor addresses:** The `\S+` capture group for `neighbor_ip` will match
   IPv6 addresses, but validate against real IPv6 syslog samples to confirm no
   whitespace or bracket formatting breaks the match.
3. **VRF name format:** VRF names with spaces or special characters may not be
   captured correctly by `\S+`. If non-default VRFs with complex names are in scope,
   adjust the capture group.
5. **`component: CONTROLLER`:** The schema enum does not include a `ROUTING` value.
   `CONTROLLER` is the closest valid enum value for a BGP routing protocol process
   fault. If a future schema revision adds a `ROUTING` component, this should be
   updated.
