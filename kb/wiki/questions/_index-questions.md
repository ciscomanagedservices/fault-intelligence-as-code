# Questions

## What Belongs Here

**Purpose:** Filed answers to questions asked by operators or the troubleshooting agent, preserved for reuse.

**Types of content that belong here:**
- Answered operator queries ("How do I check BGP peer state on a Juniper MX?")
- Agent diagnostic conclusions ("Why was circuit X flapping on 2026-04-15?")
- Recurring how-to questions that don't yet have a runbook
- Clarification questions resolved during an incident

**Boundary:** This folder is for *question-and-answer pairs*, not procedures (those go in `runbooks/`) or policies (those go in `business-rules/`). If a question's answer becomes a repeatable procedure, promote it to a runbook. If it reveals a known issue, file it there too.
